# CookCue visual identity

CookCue is a cooking companion that keeps attention on what matters now. The visual language should feel warm, calm and practical rather than like a recipe magazine.

## Mark

The mark is an open circular stroke shaped like a C with a small cue dot. It combines three ideas:

- CookCue's initial C
- a timer/progress ring
- a visual cue that says "pay attention here"

Keep the mark simple. Do not add cutlery, chef hats, flames or detailed food illustrations.

## Palette

- Paprika — #C8542E — primary actions and the app icon
- Espresso — #2A1B16 — primary text and dark surfaces
- Cream — #FFF8F1 — main light background
- Sand — #F3E5D8 — secondary surfaces
- Herb — #5C6B4C — supporting status/accent
- Honey — #F2B84B — cue dot and attention accent

Dark mode uses Espresso as the base with warmer light text and a brighter Paprika accent.

## Typography

Use the platform sans-serif / Material typography. CookCue should look native and highly readable while cooking. Use weight and hierarchy instead of a decorative display font.

## UI principles

1. The current cooking action is always the visual focus.
2. Time is large and glanceable.
3. Primary actions use Paprika and short verbs: SPUSTIŤ, HOTOVO.
4. Tips and secondary timers are quieter than the active step.
5. Rounded corners and line icons should feel friendly, not playful.
6. On Wear OS, optimize for a one-second glance: action, time, button.
